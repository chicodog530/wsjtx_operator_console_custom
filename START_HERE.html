WSJT-X Operator Console 1.1

This guide assumes you are comfortable using WSJT-X but are not a computer technician. Follow the steps in order. You do not need to edit program files.

1. What this program does

Operator Console is a companion for WSJT-X. WSJT-X still handles receiving, decoding, and transmitting. Operator Console reads information from WSJT-X and presents it in a larger browser dashboard with a waterfall, maps, logbook information, and station recommendations.

2. Before starting

You need:
  • Windows 10 or Windows 11
  • WSJT-X already installed and working
  • Python 3 installed from python.org, with Add Python to PATH checked during installation
  • Your radio and WSJT-X audio already working normally

3. Tell WSJT-X where to send its data

  1. Open WSJT-X.
  2. Click File, then Settings.
  3. Click the Reporting tab.
  4. Find the UDP Server section.
  5. Set UDP Server to 127.0.0.1.
  6. Set UDP Server port number to 2237.
  7. Check Accept UDP requests.
  8. Click OK.
Using JTAlert or another WSJT-X companion?
Only one program may receive WSJT-X UDP data directly on the same port. If you already use a UDP forwarding or multicast arrangement, keep that arrangement and configure Operator Console to receive the forwarded packets. Do not randomly change ports unless you know where the other program forwards them.

4. Start Operator Console

  1. Extract the entire ZIP file into a normal folder. Do not run it from inside the ZIP.
  2. Double-click run_windows.bat.
  3. The first start may take several minutes while Python installs the required components.
  4. Leave the black command window open while using the program.
  5. Your browser should open automatically. If it does not, open http://127.0.0.1:8080.

5. Enter your station information

  1. Click Settings at the top of the page.
  2. Enter your amateur radio callsign.
  3. Enter your Maidenhead grid, such as EM27.
  4. Choose miles or kilometers.
  5. Click the button to save settings.

6. Connect your WSJT-X log

The normal WSJT-X log is usually here:

C:\Users\YOUR_WINDOWS_NAME\AppData\Local\WSJT-X\wsjtx_log.adi

  1. In Operator Console, open Settings.
  2. Paste the complete path into the ADIF path box.
  3. Do not place quotation marks around the path.
  4. Save settings.

If you cannot see the AppData folder, press Windows key + R, type %LOCALAPPDATA%\WSJT-X, and press Enter.

7. Start the waterfall

  1. Return to the Dashboard.
  2. In the Live Audio Waterfall section, open the audio-device list.
  3. Select the same radio USB recording device used as the WSJT-X input.
  4. Press START WATERFALL.

The waterfall can use the same input as WSJT-X on most Windows systems. If the device refuses to open, make sure Windows audio “Exclusive Mode” is disabled for that recording device.

8. Adjusting the waterfall

  • Speed: lower it when signals move down the screen too quickly. The 65% default is slower than the original release.
  • Zoom: increase it to spread a smaller frequency range across the screen.
  • Pan: drag the waterfall left or right. You can also hold Shift while using the mouse wheel.
  • Mouse wheel: zooms around the frequency under the pointer.
  • Follow RX: keeps the zoomed display centered on the WSJT-X RX frequency.
  • Minimap: the narrow strip under the waterfall shows the entire 0–4000 Hz passband. Click it to move quickly.
  • Detach: opens the waterfall in a separate resizable window for another monitor.
  • Reset View: returns to the complete 0–4000 Hz display.

Your waterfall choices are remembered automatically by that browser.

10. Common problems

The page opens but shows no frequency or decodes
  • Confirm WSJT-X is running and actively monitoring.
  • Recheck the Reporting settings: 127.0.0.1 and port 2237.
  • Close duplicate copies of Operator Console. Only one copy can use port 2237.
  • Allow Python through Windows Firewall if prompted.
The waterfall is blank
  • Select the correct recording device and press START WATERFALL.
  • Confirm WSJT-X itself is receiving audio.
  • Turn off Exclusive Mode in Windows Sound device properties.
The browser says the address is already in use
  • Another copy is still running. Close its black command window or end the matching Python process in Task Manager.

11. Closing the program

Close the black command window that opened with the program. Closing only the browser tab does not stop the program.

Your settings and logbook database survive upgrades.
They are stored in %LOCALAPPDATA%\WSJTX-Operator-Console, not inside the extracted program folder.
