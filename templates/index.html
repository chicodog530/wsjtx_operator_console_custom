First-time setup

Three things are required before live data appears

  1. Enter your callsign and Maidenhead grid in Settings.
  2. In WSJT-X open File → Settings → Reporting, set UDP Server to 127.0.0.1, port to 2237, and check Accept UDP requests.
  3. For the waterfall, select the same USB audio input that WSJT-X uses and press START WATERFALL.

The full beginner guide is included as START_HERE.html in the program folder.

LoTW Auto-Logging

To use LoTW Auto-Logging, you must have the ARRL TrustedQSL (TQSL) application installed on this computer and configured with your active Callsign Certificate.

Requirements:

  • TQSL Executable Path: The path to the tqsl.exe program on your computer. Usually C:\Program Files (x86)\TrustedQSL\tqsl.exe.
  • Station Location: If you use multiple locations in TQSL, type the EXACT name of the Station Location you want to use. If you only have one location, you can usually leave this blank.
  • Certificate Password: If you protected your Callsign Certificate with a password in TQSL, enter it here. Otherwise, leave it blank.

How it works: The console will silently generate an ADIF file for your new QSOs and pass it to TQSL to sign and upload in the background.

WSJT-X Operator Console 1.1

A local browser companion for WSJT-X. WSJT-X remains responsible for decoding and transmitting.

Version 1.1 changes

  • Adjustable waterfall speed with a slower 65% default.
  • 1×–8× horizontal zoom, drag panning, mouse-wheel zoom, and Shift+wheel panning.
  • Optional automatic centering on the WSJT-X RX frequency.
  • Full-passband minimap showing the visible region.
  • Classic, high-contrast, and grayscale palettes.
  • Persistent waterfall preferences and a detachable waterfall window.
